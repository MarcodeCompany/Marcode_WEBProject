⚡ Hubungkan Project Supabase Anda

Masukkan Project URL dan Anon Public Key dari dashboard Supabase Anda (Menu Project Settings → API).

  1. Buat project gratis di supabase.com/dashboard.
  2. Buka menu SQL Editor, copy-paste isi file supabase-setup.sql yang ada di folder project ini, lalu klik Run.
  3. Buka menu Authentication → Users → Add User → Create New User untuk membuat email & password login Admin Anda.
  4. Buka menu Project Settings → API, lalu tempel Project URL dan anon public key di bawah ini:

💡 Tips Deploy: Agar permanen untuk semua pengunjung saat di-push ke GitHub Pages, tempel juga URL & Key tersebut ke dalam file supabase-config.js.
